# Student Event Registration Formatter

## Description
A simple Python program that collects student
information and event details. It formats text
and displays the event date in a readable format.

## Programming Language
Python

## Features
- Accepts student first and last name.
- Accepts section and event name.
- Accepts event year, month, and day.
- Formats names and event information.
- Displays a readable event date.

## String Methods Used
- strip()
- title()
- upper()

## Date/Time Feature Used
- datetime
- strftime()

## Sample Output
Name: Juan Dela Cruz
Name Code: JUAN DELA CRUZ
Section: MAGNESIUM
Event: Science Fair
Event Date: June 3, 2026
